# 旅行共編網頁（Google Apps Script 版）

自訂介面的旅行規劃網頁，資料存在 Google 試算表，**免費、不用架主機**，朋友打開網址就能編輯，不需要登入。

功能：
- 🗓️ **行程時間軸**：依日期分組（Day 1、Day 2…）、依時間排序。可設類型（交通／景點／餐廳／住宿／其他）、地點（自動連到 Google 地圖）、備註，並標記「待確認／已確定」。
- 📌 **候選清單＋投票**：想去的景點、餐廳先放進候選，大家按 👍／👎 投票，依票數排序；決定後按「排入行程」選日期時間，就會移到行程時間軸。
- 💬 **留言討論**：行程和候選卡片上都可以留言，有新留言會出現紅點；開著留言視窗時每 15 秒自動抓新留言。候選排入行程時，留言會一起帶過去。
- 🖼️ **照片**：候選可放 1 張封面（IG、部落格截圖），行程可放最多 6 張附件（車票、QR code、訂位確認）。上傳前先在手機壓縮，存到你指定的 Google 雲端硬碟資料夾（`Code.gs` 最上方的 `UPLOAD_FOLDER_ID`）；點縮圖可全螢幕瀏覽。刪除項目時照片會移到垃圾桶，復原時一起救回。
- 🗺️ **單日路線地圖**：每天標題旁的「路線」按鈕，依時間順序把當天地點串成 Google 地圖路線（最多 10 個地點）。
- 🎒 **行李／待辦清單**：行李分「每人都要帶」（各自勾選，看得到誰準備好了）和「共用物品」（指定一人負責帶）；待辦事項可指派負責人與期限，過期會提醒。可一鍵匯入常用清單。
- 💰 **預算分攤**：記錄誰先付、哪些人分攤，自動算出每人已付、應付、結餘，並給出最少轉帳次數的結算建議。
- 💱 **多幣別記帳**：每筆支出可選台幣或外幣（預設 THB），匯率由 Google 財經自動抓取（抓不到時改用 open.er-api.com），也可以手動改成刷卡帳單的實際匯率。每筆記下當時匯率，全部換算成結算幣別（TWD）後再分攤。
- 🕘 **修改紀錄與復原**：每次新增、修改、刪除都會記錄「誰、什麼時候、改了什麼」，改錯了可以一鍵復原（復原也能再復原）。紀錄存在「紀錄」工作表，保留最近約 300 筆。
- ⚠️ **多人同時編輯保護**：兩個人同時打開同一筆來改，後儲存的人會收到提醒，可以選擇覆蓋或放棄並查看最新內容，不會默默蓋掉別人的修改。
- ⚙️ **設定**：旅行名稱、出發／回程日、成員、結算幣別與外幣。
- 每 30 秒自動同步，手機、電腦都能用，支援深色模式。

## 部署步驟（約 5 分鐘）

1. 到 [Google 試算表](https://sheets.new) 建立一份新的空白試算表，取個名字，例如「東京旅行」。
2. 點選單 **擴充功能 → Apps Script**。
3. 在 Apps Script 編輯器中：
   - 把預設的 `程式碼.gs`（或 `Code.gs`）內容全部刪掉，貼上本資料夾的 [`Code.gs`](./Code.gs)。
   - 點左側「檔案」旁的 **＋ → HTML**，檔名輸入 `Index`（不用加 `.html`），把內容全部刪掉，貼上 [`Index.html`](./Index.html)。
   - 按 💾 儲存。
4. 上方函式選單選 `setup`，按 **執行**。第一次會要求授權：選你的 Google 帳號 → 「進階」→「前往（不安全）」→「允許」。
   （這是你自己的程式，只會存取這份試算表。）執行後試算表裡會多出「行程」「分攤」「設定」三個工作表。
5. 右上角 **部署 → 新增部署作業**：
   - 類型選 **網頁應用程式**
   - 執行身分：**我**
   - 誰可以存取：**所有人**
   - 按「部署」，複製產生的 **網頁應用程式網址**（`https://script.google.com/macros/s/.../exec`）。
6. 把網址傳給另外三人，大家加入書籤或「加到主畫面」即可。
7. 打開網頁 → 到「設定」填旅行名稱、日期、成員名字 → 每個人在上方「我是」選自己的名字。

## 之後要修改程式

改完 Apps Script 的程式碼後，要到 **部署 → 管理部署作業 → ✏️ 編輯 → 版本選「新版本」→ 部署**，網址不變，大家重新整理就會看到新版。

## 從舊版更新

把 `Code.gs` 和 `Index.html` 兩個檔案的內容**全部取代**成新版，存檔後執行一次 `setup`（會自動補上新的工作表，例如「候選」「清單」「紀錄」「留言」），再「管理部署作業 → 編輯 → 新版本 → 部署」。原本的行程與分攤資料不會受影響（舊的支出會被視為結算幣別）。

> 加入照片功能後，執行 `setup` 時 Google 會要求「存取雲端硬碟」的權限；授權畫面寫的是「所有檔案」，但程式只會在 `UPLOAD_FOLDER_ID` 指定的資料夾裡新增、移到垃圾桶。照片會設成「知道連結的人可以查看」，請勿上傳護照、證件等敏感照片。

> 加入多幣別後，執行 `setup` 時 Google 會多要求一個「連線到外部服務」的權限，這是抓備援匯率用的，請按允許。執行後可在「執行紀錄」看到目前抓到的匯率。

## 注意事項

- 「所有人」都能存取代表**拿到網址的人都能編輯**，網址請只傳給同行的人，不要公開張貼。
- 試算表本身只有你看得到（除非你另外分享），你可以直接在試算表裡查看、修改或備份資料。
- 免費帳號的 Apps Script 每日用量對 4 人規劃旅行綽綽有餘。
- 本機直接用瀏覽器打開 `Index.html` 會進入「本機預覽」模式（資料只存在你自己的瀏覽器），可以先看介面長什麼樣子。
