# 旅行共編網頁（Google Apps Script 版）

自訂介面的旅行規劃網頁，資料存在 Google 試算表，**免費、不用架主機**，朋友打開網址就能編輯，不需要登入。

功能：
- 🗓️ **行程時間軸**：依日期分組（Day 1、Day 2…）、依時間排序。可設類型（交通／景點／餐廳／住宿／其他）、地點（自動連到 Google 地圖）、備註，並標記「待確認／已確定」。
- 💰 **預算分攤**：記錄誰先付、哪些人分攤，自動算出每人已付、應付、結餘，並給出最少轉帳次數的結算建議。
- ⚙️ **設定**：旅行名稱、出發／回程日、成員、記帳幣別。
- 每 30 秒自動同步，手機、電腦都能用，支援深色模式。

## 部署步驟（約 5 分鐘）

1. 到 [Google 試算表](https://sheets.new) 建立一份新的空白試算表，取個名字，例如「東京旅行」。
2. 點選單 **擴充功能 → Apps Script**。
3. 在 Apps Script 編輯器中：
   - 把預設的 `程式碼.gs`（或 `Code.gs`）內容全部刪掉，貼上本資料夾的 [`Code.gs`](./Code.gs)。
   - 點左側「檔案」旁的 **＋ → HTML**，檔名輸入 `Index`（不用加 `.html`），把內容全部刪掉，貼上 [`Index.html`](./Index.html)。
   - 按 💾 儲存。
4. 上方函式選單選 `setup`，按 **執行**。第一次會要求授權：選你的 Google 帳號 → 「進階」→「前往（不安全）」→「允許」。
   （這是你自己的程式，只會存取這份試算表。）執行後試算表裡會多出「行程」「分攤」「設定」三個工作表。
5. 右上角 **部署 → 新增部署作業**：
   - 類型選 **網頁應用程式**
   - 執行身分：**我**
   - 誰可以存取：**所有人**
   - 按「部署」，複製產生的 **網頁應用程式網址**（`https://script.google.com/macros/s/.../exec`）。
6. 把網址傳給另外三人，大家加入書籤或「加到主畫面」即可。
7. 打開網頁 → 到「設定」填旅行名稱、日期、成員名字 → 每個人在上方「我是」選自己的名字。

## 之後要修改程式

改完 Apps Script 的程式碼後，要到 **部署 → 管理部署作業 → ✏️ 編輯 → 版本選「新版本」→ 部署**，網址不變，大家重新整理就會看到新版。

## 注意事項

- 「所有人」都能存取代表**拿到網址的人都能編輯**，網址請只傳給同行的人，不要公開張貼。
- 試算表本身只有你看得到（除非你另外分享），你可以直接在試算表裡查看、修改或備份資料。
- 免費帳號的 Apps Script 每日用量對 4 人規劃旅行綽綽有餘。
- 本機直接用瀏覽器打開 `Index.html` 會進入「本機預覽」模式（資料只存在你自己的瀏覽器），可以先看介面長什麼樣子。
